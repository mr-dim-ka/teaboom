# TeaBoom

Тестовое задание на позицию верстальщика.

## Запуск проекта

Для работы проекта необходимы [Node.js](https://nodejs.org/en/download) и [npm](https://www.npmjs.com/).

Проверить установленные версии:

```bash
node -v
npm -v
```

### 1. Установка зависимостей

В корне проекта выполнить:

```bash
npm install
```

### 2. Запуск проекта

```bash
npm run dev
```

Запустится локальный сервер и проект автоматически откроется в браузере.
Адрес локального сервера будет указан в терминале.
